Access Control을 사용하여 RustDesk Server Pro에서 어떤 사용자나 그룹이 어떤 장치에 연결할 수 있는지 결정하십시오.

## RustDesk Server Pro의 Access Control이란?

Access Control은 사용자나 그룹이 장치에 접근할 수 있는지를 결정합니다. 이는 연결 시작 후 운영자가 무엇을 할 수 있는지가 아니라, 연결 자격에 관한 것입니다. 세션 내 권한 설정을 위해서는 [Control Role](/docs/en/self-host/rustdesk-server-pro/control-role/)를 사용하십시오.

## Access Control 빠른 답변

- Access Control은 누가 어떤 장치에 연결할 수 있는지 결정합니다.
- 사용자 할당, 장치 그룹 및 교차 그룹 접근 설정을 통해 작동합니다.
- 한 장치는 한 사용자, 한 장치 그룹 또는 둘 다에 할당될 수 있습니다.
- 비활성화된 사용자와 비활성화된 장치에는 접근할 수 없습니다.
- 장치 그룹 권한과 사용자 그룹 권한을 조합해 접근을 허용할 수 있습니다.

## 가장 먼저 구성해야 할 사항은 무엇인가요?

1. 장치를 어떻게 할당할지 결정하세요: 직접 사용자에게, 장치 그룹에, 또는 둘 다에 할당할지 선택하세요.
2. 사용자가 자신의 그룹 외부의 장치에 접근해야 하는 경우 사용자 그룹에 대한 교차 그룹 규칙을 설정하세요.
3. 사용자별 할당보다 그룹 기반 장치 접근 관리가 더 쉬울 때 장치 그룹 규칙을 추가하세요.

## 장치 접근 권한

장치는 단일 사용자, 단일 장치 그룹, 또는 둘 다에 할당될 수 있습니다.

장치가 사용자에게 할당되면 해당 사용자, 사용자 그룹 또는 적절한 교차 사용자 그룹 설정을 통해 접근할 수 있습니다.

장치가 장치 그룹에 할당되면 적절한 교차 사용자-장치 그룹 설정을 통해 접근할 수 있습니다.

장치를 사용자에게 할당하는 방법은 세 가지가 있습니다:
- 콘솔 장치 페이지를 통해
- 클라이언트 측에서 지정된 사용자 계정으로 로그인하여
- 명령줄을 통해 할당하기

장치를 장치 그룹에 할당하는 방법은 두 가지가 있습니다:
- 콘솔 장치 페이지를 통해
- 명령줄을 통해 할당하기

다음 두 가지 상황에서는 장치에 접근할 수 없게 됩니다:
- 콘솔 장치 페이지에서 장치 `disable`로 설정하기
- 콘솔 사용자 페이지에서 사용자 `disable`로 설정하기

## 사용자 그룹 접근 설정

웹 콘솔의 그룹 페이지로 이동해 `Edit`를 클릭하여 아래와 같이 교차 그룹 설정을 편집하세요.

`Access with other groups`에 대한 변경 사항은 `OK` 버튼을 클릭할 필요 없이 즉시 적용됩니다.

`Can access to`와 `Can be accessed from`는 거의 동일한 기능을 제공하며, 편의를 위해 두 옵션을 모두 제공합니다. 그러나 이로 인해 약간의 혼란이 생길 수 있습니다.

제어 측에 할당된 사용자와 그룹은 웹 콘솔에서 할당된 사용자가 아니라, 로그인한 사용자에 의해 결정됩니다. 특정 제어 측에는 iOS 클라이언트와 웹 클라이언트처럼 장치 ID가 없는 경우가 있기 때문에 이렇게 설계했습니다.

## 장치 그룹 접근 설정

장치 그룹은 접근 권한을 관리하는 또 다른 방법을 제공합니다. 주요 규칙은 다음과 같습니다:

1. 한 장치는 오직 하나의 장치 그룹에만 추가될 수 있습니다.
2. 사용자나 사용자 그룹에 대해 장치 그룹의 접근 권한을 설정할 수 있습니다. 이러한 권한은 사용자 그룹 접근 권한과 누적됩니다—즉, 사용자 그룹 권한이나 장치 그룹 권한 중 어느 쪽이든 접근을 허용하면 접근이 가능합니다.
3. 할당되지 않은 장치가 장치 그룹에 추가되면 더 이상 '할당되지 않음' 상태가 아닙니다.

{{% notice note %}}
장치 그룹 기능을 사용하려면 RustDesk 클라이언트 >= 1.3.8 및 RustDesk Server Pro >= 1.5.0이 필요합니다.
{{% /notice %}}
