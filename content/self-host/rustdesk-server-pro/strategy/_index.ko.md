RustDesk 서버 프로에서 전략을 사용하여 여러 RustDesk 장치에 클라이언트 정책 및 보안 설정 변경 사항을 한 번에 배포하십시오.

전략은 RustDesk 관리자가 클라이언트 설정 페이지의 보안 옵션을 일괄적으로 업데이트할 수 있도록 하는 도구입니다. 관리자는 서로 다른 전략을 생성하고 이를 다양한 장치에 적용할 수 있습니다.

## RustDesk 서버 프로의 전략이란?

전략은 RustDesk 서버 프로에서 클라이언트 설정을 위한 일괄 정책 레이어입니다. 모든 클라이언트를 수동으로 변경하지 않고도 많은 장치나 사용자 간에 보안 또는 동작 설정을 표준화하려는 경우에 사용하십시오.

## 전략에 대한 간단한 답변

- 전략은 클라이언트의 일괄 구성 관리를 위한 것입니다.
- 한 장치는 동시에 하나의 유효한 전략에만 적용됩니다.
- 장치 전략이 가장 높은 우선순위를 가집니다.
- 사용자 전략은 장치 그룹 전략을 덮어씁니다.
- 전략이 비활성화되면, 해당 전략에 할당된 장치는 더 이상 해당 전략에 의해 관리되지 않습니다.

## 어떤 전략 할당이 우선일까요?

| Strategy type | Priority |
| --- | --- |
| Device Strategy | Highest |
| User Strategy | Middle |
| Device Group Strategy | Lowest |

## 전략 생성하기

`+` 버튼을 클릭하여 새 전략을 생성할 수 있으며, 전략 위에 마우스를 가져가 메뉴를 클릭하면 전략에 다양한 작업을 수행할 수 있습니다.

팝업 메뉴에서 전략을 `Enable` 또는 `Disable`로 선택하거나, `Rename`, `Duplicate` 또는 `Delete`로 변경할 수 있습니다. 또한 `Edit Devices`를 클릭해 해당 전략에 적용된 장치를 수정하거나, `Edit Users`를 클릭해 해당 전략에 적용된 사용자를 수정할 수도 있습니다.

전략 메뉴의 오른쪽에는 전략의 우선순위를 고려해 실제로 해당 전략에 적용된 장치의 수를 확인할 수 있습니다.

![](/docs/en/self-host/rustdesk-server-pro/strategy/images/strategy_menu.png)

## 장치 전략, 사용자 전략 및 장치 그룹 전략

전략은 다음과 같은 우선순위 순서에 따라 적용됩니다:
1. 장치 전략 (가장 높은 우선순위)
2. 사용자 전략
3. 장치 그룹 전략 (가장 낮은 우선순위)

각 장치는 동시에 하나의 전략에만 관리될 수 있습니다. 우선순위 시스템은 다음과 같이 작동합니다:
- 장치 전략은 사용자 전략과 장치 그룹 전략 모두를 우선시합니다.
- 사용자 전략은 장치 그룹 전략을 우선시합니다.
- 장치 그룹 전략은 장치 전략이나 사용자 전략이 지정되지 않은 장치 그룹 내 모든 장치에 적용됩니다.


## 장치 편집하기

`Edit Devices` 메뉴를 클릭하면 모든 장치를 표시하는 편집 대화상자가 열립니다. 체크박스의 선택 상태를 변경한 후 `Save` 버튼을 클릭해 현재 페이지에서 변경한 장치 설정을 적용할 수 있습니다. 다른 페이지의 장치를 수정해야 한다면 해당 페이지로 이동하십시오. 오른쪽 상단의 드롭다운 메뉴를 사용해 장치를 필터링할 수도 있습니다.

전략 열 형식: 장치 전략/사용자 전략/장치 그룹 전략, 또는 기본 전략인 "-"입니다.

"demo1" 메뉴에서 `Edit Devices`를 클릭했을 때 나타나는 대화상자의 예시입니다. 이 예시에서는 "1981241962" 장치는 "demo3" 전략에 적용되고, "1279471875" 장치는 "demo2" 전략에 적용되며, "a123456" 장치는 "demo1" 전략에 적용되고, "1227624460" 장치는 기본 전략에 적용됩니다.

![](/docs/en/self-host/rustdesk-server-pro/strategy/images/edit_devices.png)

## 사용자 편집하기

`Edit Users` 메뉴를 클릭하면 모든 사용자를 표시하는 편집 대화상자가 열립니다. 체크박스의 선택 상태를 변경한 후 `Save` 버튼을 클릭해 현재 페이지에서 변경한 사용자 설정을 적용할 수 있습니다. 다른 페이지의 사용자를 수정해야 한다면 해당 페이지로 이동하십시오. 오른쪽 상단의 드롭다운 메뉴를 사용해 사용자를 필터링할 수도 있습니다.

"demo2" 메뉴에서 `Edit Users`를 클릭했을 때 나타나는 대화상자의 예시입니다. 이 예시에서는 "admin" 사용자는 "default" 전략에 적용되고, "user1" 사용자는 "demo2" 전략에 적용되며, "user2" 사용자는 "demo3" 전략에 적용됩니다.

![](/docs/en/self-host/rustdesk-server-pro/strategy/images/edit_users.png)

## 장치 그룹 편집하기

`Edit Device Group` 메뉴를 클릭하면 모든 장치 그룹을 표시하는 편집 대화상자가 열립니다. 체크박스의 선택 상태를 변경한 후 `Save` 버튼을 클릭해 현재 페이지에서 변경한 장치 그룹 설정을 적용할 수 있습니다. 다른 페이지의 장치 그룹을 수정해야 한다면 해당 페이지로 이동하십시오. 오른쪽 상단의 드롭다운 메뉴를 사용해 장치 그룹을 필터링할 수도 있습니다.

"demo1" 메뉴에서 `Edit Device Group`를 클릭했을 때 나타나는 대화상자의 예시입니다. 이 예시에서는 "device_group1" 장치 그룹은 "demo1" 전략에 적용되고, "group2" 장치 그룹은 "demo2" 전략에 적용되며, "group3" 장치 그룹은 "default" 전략에 적용됩니다.

![](/docs/en/self-host/rustdesk-server-pro/strategy/images/edit_device_groups.png)

## 전략 동기화

각 장치는 단 하나의 전략에만 관리될 수 있으며, 해당 전략이 비활성화되면 장치는 더 이상 어떤 전략에도 관리되지 않게 됩니다. 전략을 동기화할 때 RustDesk는 로컬 및 서버 전략 타임스탬프를 기록해 동기화가 필요한지 판단합니다. 즉, 전략 동기화가 완료된 후:

* 사용자가 일부 옵션을 변경하면 클라이언트는 사용자의 옵션을 사용합니다.
* 관리자가 전략 내용을 변경하면 클라이언트의 옵션이 동기화됩니다.
* 관리자가 장치가 속한 전략을 변경하면 클라이언트의 옵션이 동기화됩니다.

## 전략 편집하기

전략 하단에서 `Edit`를 클릭해 수정한 후 `Submit`를 클릭하십시오. 전략은 30초 이내에 장치에 동기화됩니다.
