이 Windows 가이드를 사용하여 RustDesk를 설치하고, Windows 클라이언트를 패키지화하거나 배포하며, 관리되는 환경에서 MSI 또는 휴대용 권한 상승 워크플로우를 처리하십시오.

## 어떤 Windows 가이드를 선택해야 할까요?

| 필요 | 최적의 가이드 |
| --- | --- |
| 표준 Windows 클라이언트 설치 | [Windows 클라이언트 개요](/docs/en/client/windows/) |
| 관리형 배포, 무인 설치 또는 패키징 | [MSI](/docs/en/client/windows/msi/) |
| 권한 상승 지원이 포함된 휴대용 모드 | [Windows 휴대용 권한 상승](/docs/en/client/windows/windows-portable-elevation/) |

## Windows 빠른 답변

- 대부분의 최종 사용자는 표준 설치 프로그램을 사용하십시오.
- 기업 롤아웃 및 스크립트 기반 배포에는 MSI 가이드를 사용하십시오.
- 휴대용 모드에서 관리자 프롬프트가 필요한 경우 휴대용 권한 상승을 사용하십시오.
- 자체 호스팅하는 경우 이 가이드와 [클라이언트 배포](/docs/en/self-host/client-deployment/)를 결합하여 서버 측 롤아웃 설정을 구성하십시오.
